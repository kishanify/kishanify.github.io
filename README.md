# Kishan Singh | Creative Portfolio

Welcome to the repository powering my personal portfolio website, hosted via GitHub Pages at [kishanify.github.io](https://kishanify.github.io). 

This platform serves as a curated showcase of my creative work, digital marketing strategy, visual arts, and technical projects.

---

## Overview

The goal of this site is to deliver an intuitive, responsive, and visually compelling experience highlighting:
- **Creative Direction & Visual Design:** Digital art, concept visuals, and UI aesthetics.
- **Analytics & Strategy:** Case studies and projects blending data-driven performance with creative execution.
- **Interactive Web Design:** Clean typography, seamless navigation, and modern web responsiveness.

---

## Tech Stack & Architecture

- **Deployment:** GitHub Pages
- **Frontend:** HTML5, Modern CSS3, JavaScript
- **Styling:** Custom CSS / Minimalist design principles focused on accessibility and load performance
- **Version Control:** Git & GitHub
